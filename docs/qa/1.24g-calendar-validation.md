# 1.24g — Calendar and FA Cup fixture processing validation

## Implemented on development branch

The game previously walked all `seasonFixtures` once per FA Cup round and again per pending cup tie when checking domestic league rescheduling. The 1.24g candidate now:

1. Collects the current season's FA Cup fixtures into a per-call round index, including pending fixtures.
2. Builds a temporary date index for unfinished domestic league fixtures only when FA Cup rescheduling is needed.
3. Preserves original global fixture ordering when an earlier cup moves a league match onto the date of a later cup tie.
4. Updates the per-call cup-round index after creating a new round.
5. Keeps penalties, cup trophies, league rescheduling, inbox events, save writes and the 1.24b–1.24f optimizations in place.

The index is scoped to each invocation. It is not serialized and cannot persist outdated fixtures across a season rollover, transfer or replay.
