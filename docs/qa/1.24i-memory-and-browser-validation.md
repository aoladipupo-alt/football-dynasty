# Football Dynasty 1.24i — memory cleanup and real browser save/reload

## Implemented in cumulative development candidate

1. **Release inactive foreign-academy compression buffers when switching save slots, forcibly reloading a slot, or starting a fresh career.** Prior to this fix the previous slot's world-academy array and compressed shadow sidecar could remain strongly referenced until another world save. This update clears only serialization caches; it never deletes players, clears browser storage, or changes the save format. Ordinary same-session resume continues to reuse the active cache.
2. **Repair a real saved-career load failure found by Chromium testing.** The career repair module called `normalizeRosterName` but the helper was private to the earlier player-roster loader closure. Real-browser testing showed `ReferenceError: normalizeRosterName is not defined` after opening a newly saved career; the UI offered RETRY CONTINUE and preserved the saved data. The candidate now copies the *exact existing* Unicode name normalizer into the distinct career-manager closure, rather than introducing a different identity-matching rule.
