# 1.24e — Matchday AI lineup selection optimization

## Change

The actual `autoAssign(playerIds, formation)` function is used when creating AI
matchday lineups. Previously the formation's slot rankings evaluated
`playerSlotScore(player, position)` repeatedly inside multiple `filter`
passes and sort comparators. The candidate now memoizes each player's score
for each position **only for the duration of one lineup assignment**.

This leaves selection, lineup ordering and positional suitability behavior
unchanged for the tested scenarios, while avoiding repeated comparisons and
position-suitability evaluations. Each new match, squad update or assignment
starts with an empty cache; it is not persisted into career data.
