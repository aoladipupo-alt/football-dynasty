# 1.24d — daily training / simulation regression record

## Update (development branch only)
The calendar processes `applyTrainingDay()` each game day. Previously the combined first-team + academy rows used `arr.findIndex()` for every player to keep the first row of each ID. That performs quadratic ID comparisons in the number of candidate rows. The 1.24d candidate keeps a `Set` and marks IDs on their **first encounter**, including when that first row is ineligible (pending player or parent-club loan). The first-row-wins rule is deliberately preserved.

The new candidate is based on the prior 1.24b (world-save) and 1.24c (save restore) candidate; it does not mutate the main-branch archive.
